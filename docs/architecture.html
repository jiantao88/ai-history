BM25 搜索引擎

  • • 纯 Rust 实现, 零外部依赖
  • • 多词查询: --all AND / 默认 OR
  • • 两遍扫描: 1) 建立语料统计 2) 评分
  • • IDF 惩罚高频词, TF 归一化文档长度
  • • k1=1.2, b=0.75 (经典 BM25 参数)
  • • --sort-time 可回退为时间排序

上下文窗口

  • • -C N 显示匹配前后 N 条消息
  • • 仿 grep -C 惯例, 开发者无学习成本
  • • saturating_sub 处理首尾边界
  • • 仅对 top-N 结果附加 (truncate 后)
  • • context_window=0 兼容旧行为
  • • JSON 输出: context_before/after 数组

会话元数据

  • • 从 tool_use 提取文件路径和工具名
  • • 从文件扩展名推断编程语言 (18 种)
  • • 错误模式检测 (5 种关键词)
  • • piggyback 已有扫描, 零额外 I/O
  • • SessionMetadata 可选 (Option)
  • • Claude + Codex 双 provider 支持
